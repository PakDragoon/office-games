# Office games

One page with every game, for a break with colleagues: `https://pakdragoon.github.io/office-games/`.

| Game | Players | Link |
| --- | --- | --- |
| **The Liar** (new) | 3 to 8 | [pakdragoon.github.io/the-liar](https://pakdragoon.github.io/the-liar/) |
| **Guesstimate** (new) | 1 to 8 | [pakdragoon.github.io/guesstimate](https://pakdragoon.github.io/guesstimate/) |
| **Thulla** | 2 to 8 | [pakdragoon.github.io/thulla](https://pakdragoon.github.io/thulla/) |
| **Wordle Party** | Up to 5 | [pakdragoon.github.io/wordle](https://pakdragoon.github.io/wordle/) |

The page is a single `index.html` with no build step. To add a game, copy one of the `<li>` cards. To retire a **New** tag, delete its `<span class="new">NEW</span>`.
